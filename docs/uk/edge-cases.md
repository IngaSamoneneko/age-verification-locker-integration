# Основні edge cases

Нижче наведено основні приклади альтернативних та помилкових сценаріїв. Перелік навмисно не є вичерпним для тестового кейсу.

### 1. Неуспішне підтвердження віку

Якщо Company X не отримує успішного результату підтвердження віку через Дію, OTP не реєструється та видача посилки не дозволяється.

### 2. Невалідний або прострочений OTP

Якщо введений код не відповідає активному OTP для посилки або завершився його TTL, комірка не відкривається, а користувач отримує повідомлення про неможливість видачі.

Інші помилкові та recovery-сценарії мають бути деталізовані під час refinement перед передачею функціоналу в розробку.

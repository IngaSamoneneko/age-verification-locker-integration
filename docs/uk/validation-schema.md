# Схема інтеграції для валідації коду

Для перевірки одноразового коду пропонується механізм **Pre-registered OTP Validation**.

```text
                     Успішне підтвердження віку
                                │
                                ▼
                           Company X
                              Backend
                                │
                                │  Генерує OTP
                                │
                                │  Реєстрація OTP
                                ▼
                    Backend нашої системи
                                │
                    Зберігає захищене
                    представлення OTP,
                    TTL та статус
                                │
                                │  Реєстрацію підтверджено
                                ▼
                           Company X
                     Мобільний застосунок
                                │
                                │  Показує OTP
                                ▼
                           Користувач
                                │
                                │  Вводить OTP
                                ▼
                         ПЗ поштомата
                                │
                                │  Запит на перевірку OTP
                                ▼
                    Backend нашої системи
                          ┌─────┴─────┐
                          │           │
                       Валідний    Невалідний
                          │           │
                          ▼           ▼
                   Позначити OTP   Відмовити
                   як використаний у видачі
                          │
                          ▼
                   Дозволити відкриття
                        комірки
